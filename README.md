# 📈 Stock Market Portfolio Tracker & Return Analyzer

![License](https://img.shields.io/badge/License-MIT-blue?style=for-the-badge)

Welcome to the **Stock Market Portfolio Tracker & Return Analyzer**! This is a comprehensive, hardcore Excel-based utility designed for investors and traders to meticulously track their equity investments, analyze portfolio performance, and calculate exact returns without relying on expensive third-party software.

## 🌟 Key Features

- **📊 Advanced Dashboard:** A clean, easy-to-read summary of your entire portfolio's health, Total P&L, and asset allocation.
- **💰 Return Analysis:** Calculates accurate metrics like Absolute Returns, Profit/Loss margins, and portfolio weightage.
- **📝 Trade Journaling:** Seamlessly log your buy and sell entries.
- **🚀 Hardcore Excel Formulas:** Built using robust and dynamic Excel functions to automate calculations and reduce manual data entry errors.
- **🔒 Complete Privacy:** Your financial data stays with you on your local machine. No cloud syncs, no data sharing.

## 📁 Repository Structure

- `final_procject_hardcore_excel.xlsx` : The core project file containing all the trackers, dashboards, and analytical tools.

## 🚀 How to Use

1. **Download the File:** Click on `final_procject_hardcore_excel.xlsx` in this repository and click the **Download** button.
2. **Open in Excel:** Open the file using Microsoft Excel (Office 365 or 2019+ recommended for best compatibility).
3. **Input Data:** Navigate to the data-entry sheet and start logging your stock symbols, buy dates, quantities, and purchase prices.
4. **Analyze:** Switch to the Dashboard/Analysis tab to see your portfolio's performance dynamically update!
